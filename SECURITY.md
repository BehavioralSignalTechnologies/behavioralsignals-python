# Security Policy

## Supported versions

We fix security problems in the latest release of
[behavioralsignals on PyPI](https://pypi.org/project/behavioralsignals/). Please check that the
problem still happens on the latest version before you report it.

## Reporting a vulnerability

Please do not report security problems in public GitHub issues.

Email both of these addresses:

- lefteris@behavioralsignals.com
- dimitris@behavioralsignals.com

Please include:

- the SDK version and Python version
- what the problem is and how it could be misused
- steps or code to reproduce it

Do not send real API keys or customer data.

We will reply to confirm we got your report and keep you updated until it is fixed.
